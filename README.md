# Counter App

A clean, modern, and responsive counter built with vanilla HTML, CSS, and JavaScript.

## Features

- Increment and decrement the counter
- Reset the value back to zero
- Responsive, mobile-friendly layout
- Modern glass-inspired card design
- Smooth button hover and press animations
- Keyboard-visible focus styles
- No frameworks or dependencies

## Built With

- HTML5
- CSS3
- JavaScript

## Getting Started

### Run locally

1. Clone or download this project.
2. Open the project folder.
3. Open `index.html` in your browser.

For a local development server, run:

```bash
python3 -m http.server 4173
```

Then visit `http://localhost:4173`.

## Controls

| Button | Action |
| :---: | :--- |
| `-` | Decrease the counter |
| `Reset` | Set the counter to `0` |
| `+` | Increase the counter |
